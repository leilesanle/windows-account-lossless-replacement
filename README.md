# windows-account-lossless-replacement

经机器上尚存的管理员账户（超级账户）无损更换 Windows 账户的实战规程 —— 一个 Muse / agent skill。

**解决什么问题**：旧账户密码不可找回、PIN 失效、微软账户锁死、自动登录失效，进不去桌面，但数据一分不能丢。

**方法**：以尚存管理员账户滩头登陆 → 全量盘点 → 新建账户验基石 → 物理移植 profile ＋ 注册表分批嫁接（身份类/应用类/UsrClass）→ 自动登录收口并重启实测 → 计划任务改绑三查（主体/触发器 UserId/引用文件 ACL）→ 外部实登验收 → 命令行删旧账户收官。

**来源**：2026-11-09/10 一台 LEGION R7000 的真实锁机救援全程实证——改指路线两败后靠判别测试定案、移植＋嫁接收官；文中的每条规矩都对应一次真实踩坑（删凭据前漏验兜底、厂商任务残留加载旧 hive、私钥 ACL 只认旧账户、登录触发器 UserId 未跟随改绑等）。

正文见 [SKILL.md](./SKILL.md)：红线、八个阶段、验收清单与实证注记俱全。
